# Binary Tree Visualizer

A simple interactive project to visualize binary tree structure and common traversal orders.

## Features

- Insert values into a binary search tree
- View traversals for:
  - inorder
  - preorder
  - postorder
- Animated node highlighting
- Clean tree layout for learning DSA concepts

## Why this matters

Binary trees are one of the most important data structures in computer science. This project demonstrates understanding of abstraction, recursion, and tree traversal patterns.

## Run locally

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
